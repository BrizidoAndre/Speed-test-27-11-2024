# Speed-test-27-11-2024

## 🚀 Coleção de Exercícios e Demonstrações Rápidas

O repositório **Speed-test-27-11-2024** é uma coleção de pequenos exercícios e projetos de demonstração, abrangendo desde o desenvolvimento *frontend* básico (HTML/CSS) até aplicações mais complexas em PHP (Yii2). O objetivo é demonstrar a versatilidade e a capacidade de implementação rápida em diferentes contextos e tecnologias.

### ✨ Projetos Incluídos

O repositório é organizado em pastas, onde cada pasta representa um projeto ou demonstração individual.

| Pasta | Descrição do Projeto | Tecnologias Principais |
| :--- | :--- | :--- |
| **A1, A6, A7, B26, B3** | Exercícios de Frontend | HTML, CSS |
| **C13** | Aplicação PHP Simples | PHP, JSON |
| **C4** | Aplicação PHP com HTML | HTML, PHP |
| **C5** | Projeto Base Yii2 | PHP (Yii2 Framework) |

#### Detalhes dos Projetos

*   **A1, A6, A7, B26, B3 (HTML/CSS):** Estes diretórios contêm exercícios focados em marcação e estilização, ideais para demonstrar proficiência em layout, design responsivo e efeitos visuais básicos.
*   **C13 (PHP/JSON):** Este projeto demonstra a capacidade de leitura e manipulação de dados em formato JSON utilizando PHP, com um arquivo `users.json` e um script `index.php`.
*   **C4 (HTML/PHP):** Este projeto combina HTML para a interface e PHP para a lógica de *backend*, incluindo um script `reverse.php`, sugerindo uma funcionalidade de manipulação de strings ou dados.
*   **C5 (Yii2 Framework):** Este é o projeto mais robusto, baseado no **Yii 2 Basic Project Template**. Ele demonstra conhecimento em arquitetura **MVC** (Model-View-Controller) e o uso de um *framework* PHP profissional. A estrutura inclui:
    *   `controllers/`: Lógica de negócio e fluxo da aplicação.
    *   `models/`: Estrutura de dados e regras de negócio.
    *   `views/`: Arquivos de visualização (interface do usuário).

### 🚀 Como Executar

Para visualizar os projetos, basta navegar até a pasta correspondente e abrir o arquivo principal (`index.html` ou `index.php`) em seu navegador.

**Para projetos HTML/CSS (A1, A6, A7, B26, B3):**

```bash
# Exemplo para o projeto A1
# 1. Clone o repositório
git clone https://github.com/BrizidoAndre/Speed-test-27-11-2024.git

# 2. Navegue até o diretório do projeto
cd Speed-test-27-11-2024/A1

# 3. Abra o arquivo index.html no seu navegador
# (Exemplo para Linux/macOS)
open index.html
```

**Para projetos PHP (C13, C4, C5):**

É necessário um servidor web local com suporte a PHP (como XAMPP, WAMP ou MAMP) para executar os arquivos `.php`. Para o projeto C5 (Yii2), a instalação e configuração do *framework* são necessárias.
